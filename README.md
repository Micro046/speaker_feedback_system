# PRISM: Slide-Aligned Feedback for Presentation Skills

PRISM stands for Presentation Insights System for Multimodal and Multilingual Feedback.

PRISM is an end-to-end presentation feedback system that analyzes a recorded talk and produces a slide-aligned coaching report.
It combines speech, slide content, and delivery cues (gaze, gesture, emotion, clothing) to generate a single actionable PDF.

## What the User Gets
- A combined PDF report with slide-by-slide feedback and overall coaching summary.
- Alignment analysis between spoken content and each slide's meaning.
- Visual delivery insights: gaze, gestures, facial expression, and clothing cues.
- Evidence-backed metrics (WPM, intelligibility, similarity scores, coverage).
- Actionable recommendations tailored to specific slides and behaviors.

## What This Project Does
- Speech analysis: transcription, fillers, speech rate, intelligibility, noise
- Slide analysis: transitions, OCR, description, layout, saved slide crops
- Face cache: dominant-speaker frames for visual modalities
- Clothing: attire profile and appropriateness
- Gaze: head-pose gaze categories (audience/script/slides)
- Emotion: per-slide and overall emotion distribution
- Gesture: semantic body-language events with timestamps

## Project Structure
- `src/speaker_feedback/`: core pipeline (speech, slide, video, tools, NeMo)
- `notebooks/`: step-by-step prototype notebook
- `data/inputs/`: input videos and assets
- `data/cache/`: local model caches
- `data/outputs/`: generated payloads and reports
- `scripts/`: environment setup helpers
- `gradio_app.py`: PRISM Gradio app (video -> PDF)

## Outputs
- `data/outputs/content_report_payload.json`
  - Slide + speech only, includes evidence intervals and alignment metrics
- `data/outputs/visual_report_payload.json`
  - Visual modalities only, includes multimodal events and timestamps
- `data/outputs/gradio/<timestamp>/presentation_feedback_report.pdf`
  - Combined PDF report generated by the Gradio app

## Environment
Create a `.env` file in the project root and set:
```
OPEN_ROUTER=your_key_here
```
The app and notebook load `.env` with `override=True`.

Optional overrides:
```
DETECTRON_MODEL_PATH=/datasets/model_best/model_best.pth
DETECTRON_CONFIG_PATH=/notebooks/data/cache/my_custom_config.yaml
OCR_MODEL_ID=Qwen/Qwen2.5-VL-3B-Instruct
WHISPER_MODEL_SIZE=small
WHISPER_LANGUAGE=en
SF_OFFLINE_MODE=1
```

Setup helpers:
- `scripts/setup_env.sh` (Linux CUDA/Jupyter)
- `scripts/setup_paperspace.py` (Paperspace model cache warmup)

## Notebook
Use:
- `notebooks/speaker_feedback.ipynb`

This notebook runs the full pipeline step-by-step and shows keys and previews after each modality.
It builds both payloads and then generates the combined PDF recommendations.

## Gradio App (Video -> PDF)
1) Warm up model caches:
```
uv run python scripts/setup_paperspace.py
```
2) Run the app:
```
uv run python gradio_app.py
```

The app prints progress logs and generates a single PDF report.

## Notes
- Per-slide report uses only speech + slide content.
- Visual report uses gaze/emotion/gesture/clothing with reliability gates.
- Slide crops are stored under `data/inputs/video/slides/<video_name>/`.
